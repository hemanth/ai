To use this app, you need Chrome 138+ with the built-in AI APIs enabled:

  1. Open chrome://flags/#optimization-guide-on-device-model
    Set to Enabled BypassPerfRequirement
  2. Open chrome://flags/#prompt-api-for-gemini-nano
    Set to Enabled
  3. Open chrome://components
    Click "Check for update" on Optimization Guide On Device Model

After enabling, relaunch Chrome to start chatting!
