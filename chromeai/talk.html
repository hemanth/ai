Benefits over Cloud APIs

  • 🔒 Local Processing: Enhanced privacy
  • ⚡ Potential for Speed: No server delays
  • 🌐 Offline Capabilities: Functions without internet
  • 💰 Cost Savings: Lower API usage costs
  • 🔄 Hybrid Approaches: Flexible options for users

Benefits over BYO AI 

  • 📦 Bandwidth Savings
  • ⚙️ Performance Optimizations
  • 🚀 Lower Entry Barrier

Goals

  • 🎯 Uniform JavaScript API for language models
  • 🔍 Abstract language model details
  • ⚠️ Handle failure cases
  • 🛠️ Flexible implementation strategies

Non-Goals

  • 🚫 Not forcing browser for language model shipping or exposure
  • 🚫 No assurance of language model quality, stability, or interoperability

Potential Goals

  • 🔍 Manage language model interactions (on-device or cloud-based)
  • 🔒 Ensure user data privacy and control
  • 📱 Provide options for on-device-only models
  • 🔖 Identify language model identifiers independently from browser versions

Zero-shot prompting


const session = await LanguageModel.create();

// Prompt the model and wait for the whole result
const result = await session.prompt("Give me a dadjoke!");
console.log(result);

// Prompt the model and stream the result
const stream = session.promptStreaming("Give me 5 dadjokes.");
for await (const chunk of stream) {
  console.log(chunk);
}

N-shot prompting


const session = await LanguageModel.create({
initialPrompts: [
    { role: "system", content: "Generate a short, humorous response to a comment. Output a single sentence." },
    { role: "user", content: "I just finished a 10k run!" },
    { role: "assistant", content: "Did you chase the ice cream truck?" },
    { role: "user", content: "I got a promotion at work!" },
    { role: "assistant", content: "Guess it's time to buy that island!" }
]
});

async function generateHumorousResponse(comment) {
    const session = await session.clone();
    return await session.prompt(comment);
}

generateHumorousResponse("I just finished a 10k run!").then(console.log);

Session Management

  • 🔄 Persistent series of interactions
  • 🔄 Cloning for unrelated continuations
  • 🚫 Destruction to free resources

const session = await LanguageModel.create({
    initialPrompts: [
        { role: "system", content: "You are a vegan chef!" }
    ]
});
    
const result = await session.prompt(`
    What will you cook for dinner today?
`);
    
const result2 = await session.prompt(`
    I don't like that dish, any other suggestion? 
`);

    
const session = await LanguageModel.create({
    initialPrompts: [
        { role: "system", content: "You are a vegan chef!" }
    ]
});
    
const session2 = await session.clone();
session.destroy();
    
// The promise will be rejected.
await session.prompt(`
    What will you cook for dinner today?
`);

window.ai.finetune

window.ai.finetune(options: FineTuneOptions)

options.model: Specifies the base model to fine-tune. defaults to "nano".
options.dataset: An optional structured dataset for fine-tuning.
options.rawText: An optional string of raw text for fine-tuning.
options.epochs: An optional number of training epochs (default may vary by implementation).
options.learningRate: An optional learning rate for the fine-tuning process.

window.ai.contextCache


async function manageConversationContext(conversationId, newMessage) {
    // Configure cache
    await window.ai.contextCache.setOptions({ maxSize: 1000, ttl: 3600000 });

    // Retrieve existing context
    let context = await window.ai.contextCache.get(conversationId);

    // Update context with new message
    context = (context ? context + "\n" : "") + newMessage;
    await window.ai.contextCache.update(conversationId, context);

    // Use updated context in AI interaction
    const response = await someAIFunction(context);

    return response;
}
