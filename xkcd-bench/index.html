TRACK 01 · EXPLAIN-BENCH PROTOCOL

Blind Multimodal Prompting & Hybrid Rubric

Every model is evaluated blind: vision models receive only the raw comic .png bytes and official hover alt text (max_tokens=4096, temperature=0.2), with zero access to ExplainXKCD ground truth.

Composite Score Formula:
0.30 × Humor + 0.30 × Domain + 0.25 × Visual + 0.15 × Alt-Text
Per-Pillar Calibration:
40% TypeSafe System One (Noul) + 60% Deterministic Reference (Stem Concept Recall + Lexical F1 @ 115 tokens)
TRACK 02 · REVERSE COMIC SEARCH RRF

BM25F + 64-Bit dHash + TypeSafe Jev Rerank

Reverse search resolves vague human memory queries ("Bobby Tables SQL injection", "whale bones inside space shuttle") and cropped comic panels across all 891 strips in three fused stages:

  • 1. BM25F Index: Field-weighted lexical retrieval (title ×4.0, concepts ×3.5, alt ×2.5, transcript ×2.0, explanation ×1.2).
  • 2. 64-Bit dHash: 9×8 LANCZOS grayscale luminance gradient hashing with normalized Hamming similarity (1 − dH / 64).
  • 3. TypeSafe Jev + RRF: Parallel System One binary judgment reranking fused via Reciprocal Rank Fusion (k = 60), achieving 100.0% Hit@1 across all 30 queries.
