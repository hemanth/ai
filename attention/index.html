04 / 10 · POSITION

Rotate vectors by word order.

Processing all words in parallel erases sequence order. Rotary Position Embedding (RoPE) twists each vector along a 3D helix according to its slot 0 → 4.

R(m) · xₘ = xₘ e^(i m θ)
05 / 10 · Q, K, V

Split one token into three roles.

Three learned matrices project “bank” into a Query (what it seeks), a Key (what it advertises), and a Value (the meaning it carries).

q = W_Q x, k = W_K x, v = W_V x
06 / 10 · ALIGNMENT

Score relevance by 3D angle.

“bank” compares its Query against every token's Key using a dot product. Aligned arrows score high; dividing by √dₖ keeps large dimensions stable.

sᵢⱼ = (qᵢ · kⱼ) / √dₖ
07 / 10 · SOFTMAX

Focus a 100% spotlight.

Softmax turns raw scores into weights that sum to 100%, while the Causal Mask hides future words (−∞) so tokens only look backward.

αᵢⱼ = softmax(Q Kᵀ / √dₖ + M)
08 / 10 · CONTEXT SHIFT

Pull meaning into focus.

Each token adds up the Value vectors weighted by its attention. Upstream words physically pull “bank” into its contextualized meaning.

x'_bank = x_bank + ∑ αⱼ vⱼ
09 / 10 · TRANSFORMER BLOCK

Run parallel heads on a highway.

Multiple attention heads track nouns, verbs, and syntax simultaneously, adding their updates onto the Residual Stream before a 4d MLP extracts facts.

y = x + MHA(x) + MLP(x)
10 / 10 · EMERGENCE

Stack layers to predict the next word.

Stacking Transformer blocks refines your sequence from raw bytes into deep context. The final layer projects onto the 50,257-token vocabulary, predicts “river”, and loops it back in.

P(next) = softmax(W_U · Block_L(x))
